Design choices: fixed 16-bit width keeps fetch and decode simple. A 4-bit opcode gives 16 instructions. 3-bit register fields give 8 registers. Branches are PC-relative so a 6-bit offset is enough for loops. Flags Z and N are updated by ALU instructions. Labels end with ':' and comments start with ';'. Numbers can be decimal or 0x hex.
